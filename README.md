# dsh-tokenrhythm-bill

**基元律动费用中心** —— DeepSeek Harness（DSH）插件，把[基元律动 tokenrhythm.studio](https://tokenrhythm.studio) 的模型清单、账户余额、用量、密钥管理与服务状态，集中到侧栏底部一个小面板里。

在 DSH 侧栏底部（设置按钮上方）点击「基元律动-费用中心」入口即可打开可拖拽面板：入口左侧是**品牌标 + 名称**，右侧常驻**总余额胶囊**（切号即刷、预警转琥珀色）；**悬停入口**可浮出**限时余额时间线**——逐笔列出每笔限时额度和「N 天后失效」（实时计算，无限时额度时不显示）；侧栏收起时只保留品牌图标。

## 功能一览

### 模型
- 顶部**分类筛选**：全部 / 文本 / 图像 / 音频 / 视频 / 向量（带计数，口径与平台模型列表页一致）
- **文本在前、图像在后，价格升序**：图像模型按图片单价、文本模型按输入单价（有折扣取折扣价）；无价格的排组尾，同价内保持平台原序
- 卡片结构对齐平台模型页：**名称 + 状态胶囊**（在线 / 测试中）headline，**模型 ID + 来源**（无问芯穹 / DeepSeek / 百炼…）副行
- **规格 / 价格两栏**：序列长度、支持模态（文本 / 图像 / 视频 / 音频 / 向量）、最大输出长度；输入 / 输出 / 缓存命中单价（折扣时划线标原价，¥x.xx/M）、图片单价
- 折扣模型：标题行最左带**「折扣」徽章**（实底绿渐变 + 白字，行内排布、不影响卡片布局），价格栏同时划线标原价；状态胶囊只显示平台状态（在线 = 绿点 / 测试中 = 琥珀点）——模型页签已无探测联动，探测详情看「状态」页签

### 余额
- **账户余额主卡**：大字展示总余额（带千分位），右侧**限时额度** + **倒计时胶囊**（≤3 天转警示色）+ **限时占比条**（一眼看出多少是「会过期的钱」），有冻结金额时一并显示
- **当日使用**：调用次数、输入 / 输出 / 缓存 tokens 与命中率、当日花费（本地 0 点起统计）
- **资金明细（v0.5.8 新增）**：把账户余额拆回来源逐笔列出——充值本金置顶，之后每笔赠送额度一行，含**赠送多少 / 已用多少 / 还剩多少 / 何时到期**，按到期早晚排序（临期的排最前）；已用完的（`USED_UP`）也保留，否则就说不清「这一路总共赠送过多少」。摘要行另给「累计赠送」「未到期」两个数
- 每 60 秒自动刷新；临期或余额不足时顶部有预警条
- 主卡上方标注**数据归属账号**（显示平台用户名，数据按账号隔离，切换账号立即刷新）
- **侧栏入口常驻余额**：不打开面板也能在侧栏底部看到当前账号余额，切换账号随之更新；**悬停入口**浮出限时余额时间线（逐笔列出每笔限时额度和「N 天后失效」，无限时额度时不显示）；设置页可把胶囊切换为**总余额 / 限时总余额**二选一
- 更长周期（30 天）的用量看「用量」页签；本页不重复放 7 日柱状图与「最近调用」——那两块每次刷新都要翻几十页 call-logs，平台约每 3 个请求就 503 一次

### 用量（v0.5.5 新增，0.5.6 / 0.5.8 优化）
- **近 30 天总花费 + 调用次数**大字主卡，下方 5 张指标卡（由粗到细）：成功 / 失败、中止、总 Tokens、输入 / 输出、缓存命中率
- **30 天热力日历**：一格一天，格子底色随当日花费深浅变化（越贵越浓），金额直接摆在格子里；周末列表头与空格另有区分。**标题行右上角有覆盖度角标**（`N / 30 天有调用 · 明细起 XXXX-XX-XX`）——空格子占多数是常态，角标说清「空的是真空」而不是「没加载出来」。悬停**有调用**的格子才浮出当日明细（模型列表 + 各自金额 / 调用数、开源节省）——当天无调用的格子没有可看的东西，不弹浮层。浮层靠左/右边缘的格子自动贴边、第一行的翻到下方，不会被面板裁掉
- **按模型 / 客户端拆分**：**左右并排各占一半宽度**（信息量相当、也常要对照着看，上下排会把面板撑到要滚两屏），各取花费前 6 名排行，带占比条
- **口径说明写死在界面上**：日历只统计最近 30 天；平台没返回明细的日子画虚线框 + 「—」；两个上游接口的 30 天合计若出现分差会显式提示「以汇总为准」，不悄悄选一个
- 每 90 秒自动刷新，可手动刷新

### 状态
- **服务总览横幅**：整体状态文案对齐官方状态页（所有系统运行正常 / 部分服务性能下降 / 部分服务中断 / 重大服务中断）带呼吸状态点，今日可用性、平均首字延迟、未解决事故一目了然
- **厂商分组折叠面板**（对齐官方状态页）：顶部 **24小时 / 7天 / 90天** 视图切换（官方同款，默认 24h）；平台网关排最前，按 DeepSeek / GLM / Kimi / MiniMax / Qwen / Seed / 其他 分组；组头显示「组名 · N 个组件 · 摘要」，有问题的组自动展开，点击组头折叠；**组体照官方页**：每通道一行（状态点 + 模型名 + 上下文 · 价格元信息 + 首字延迟 + 所选区间可用率%），下方 90 天**逐日柱条**或 24h/7d **探测粒度格子**（72/84 桶重采样、flex 铺满**无滚动条**，悬停看「时间范围 · 最差状态 · 探测次数」）
- **最近事故**：自动检测的服务中断（原因 + 开始时间 + 持续时长 + 已恢复 / 未解决标记）
- 模型页签与状态页解耦：卡片胶囊只显示平台状态（在线 / 测试中），探测详情集中在「状态」页签
- 数据经 host 后端代理（2 分钟缓存 + 上游失败回退快照），浏览器不跨域直连，每 60 秒自动刷新

### 密钥
- 查看平台 API Key 列表（只显示掩码），匹配到本机完整密钥时可一键复制完整值
- 直接新建平台 API Key
- 阶跃首页「密钥」页签里维护阶跃控制台的「接口密钥」：新建 / 复制完整值 / 删除（立即失效）；完整值只在创建时展示一次，列表只显示掩码，复制走本机 host 按需单取，不经过任何服务器

### 阶跃（StepFun）
- **提供商切换**：面板标题右侧的 `基元律动 | 阶跃 | ZCode` 切换器切到阶跃（未配置阶跃账号时这一段不出现）
- **「账户」页签（v0.5.9 起账号 + 用量二合一）**：把设置里配的**全部阶跃账号**各列一张卡，每张卡带该账号的**账户余额**与**Credit 月池**（百分比 + 内嵌进度条 + 档位 / 到期 / 续费状态），**Credit 格右上角另挂「↻ M/D 重置」**——月池什么时候刷新剩余额度，悬停看完整时间与剩余天数。账号名后面跟一个**密码胶囊**：默认打码（固定 6 个圆点，连长度都不透露），点一下才显明文，同一时刻只展开一个；没有保存密码的旧账号显示「未存密码」且不可点。每张卡可单独**查询此账号 / 展开明细**，卡上可直接**删除账号**（两段式确认）；账号**增删都在这一页**，设置页只留一个跳转入口——列表和增删同一屏，不再两处维护
- **「显示」= 纯显示偏好**：让侧栏胶囊、主卡和「接口密钥」页都跟着换成这个账号的数据。各账号会话分槽并存，**不切换登录身份、不清缓存、不触发重登**。**页签标签直接带账号**（`密钥（138****0001）`）——增删密钥不可逆，归属不该藏在二级页面里，切了「显示」不进页签就知道这堆密钥是谁的；账号还没探明时退回纯「密钥」，页签文本统一次 `nowrap` + 省略号防长账号名撑爆两格布局。密钥页顶部另有一行归属标签（「「138****0001」的密钥」），切显示账号时列表会跟着重拉——不写清楚的话，用户照旧列表删/建，动的其实是另一个账号的密钥
- **会话按账号分槽**（键 = username 小写）：`stepRpc` 省略 username 时按 `pickStepAccount` 的口径兜底到活跃账号，所以 `stepGetSess` 的省略态也必须兜底到 `activeAccount`——多账号重构时这里漏了，而四个密钥 `stepRpc` 又恰好都没传 username，于是 `ListAccessKeys` 稳定报「无可用会话」（已修）。现在四个密钥调用（列表 / 取完整值 / 创建 / 删除）全都显式带 username，测试对每处调用逐一断言。**显式传了 username 却没会话时不许兜底到活跃账号**——那正是「查 B 回了 A 的结果」这类张冠李戴 bug 的温床
- **重置时间的取值与兜底**：优先 `subscriptionResetAt`（订阅月池总表），缺失时降级到 `type=1` 桶的 `nextResetAt`。这个字段**没有实测过**（schema 注释标称秒级、与 `expired_at` 同口径），所以加了合理性窗口 `[今天-1年, 今天+3年]`——窗口外一律不显示，**宁可不显示，也不显示一个公元 5 万年的错日期**。剩余天数走**日历日口径**（0=今天、1=明天、负=已过），与限时额度到期天数一致；不用 `ceil`，否则「今晚就重置」会被算成「还剩 1 天」
- **密码不进列表响应**：账号清单只回 `pwMask` 掩码，明文走独立路由 **按需单取**（只认账号池内的 username，池外 404）——和密钥「列表只回掩码、完整值按需单取」是同一口径。删除账号时会顺手收掉已展开的明文
- **主动作收敛成一个「查询余额」**，放在页签右上角：它才对全部账号真发请求（会话失效的会先自动续期/登录，然后并发拉取），是这一页最重的动作。底部不再放「刷新」——那个按钮只是读 host 本地缓存、零网络，点下去数字不会变；它该做的事 60 秒自动轮询已经在干，且和卡片脚行真查单账号的「刷新」同名不同义，纯属误导
- **三种卡片状态一眼可辨**：**显示中**（主色描边 + 淡主色底 + 左侧竖条）、**已查询**（常规卡）、**未查询**（虚线框 + 无底色 + 「未查询」角标）。不再用整体压暗表示未查询——那会把卡上的删除按钮压得像禁用的，且一屏卡片里看不出差别
- **「显示」按钮是显示偏好，不是切换登录**：点它只把侧栏胶囊与主卡的数据源换成这个账号。各账号会话分槽并存，换显示目标不清任何人的缓存、不触发重登；账号的增删仍在设置页
- **明细默认折叠**：点「展开 ▼」才显示该账号的近 7 日 Credit 消耗柱条与账户类型 / 累计消耗 / 套餐到期 / 自动续费明细（缺项显示 `—`，两列排满不留空格）。没查过的账号不显示展开按钮，只给「查询此账号」
- **打开面板即自动查全部账号**：各账号会话**独立保存**（落盘），登过一次就长期复用。平台用户 token 寿命 30 分钟（2026-09-24 实测 `accessToken.duration` = 1800s，cookie token 与 JSON token 的 JWT `exp` 均为 30 分钟），但**过期后不用重新输密码**：`PassportService/RefreshToken` 能用旧 cookie（`Oasis-Token` + `Oasis-Webid`）换回本人的新会话——实测过期 1 分钟的 token 打 RefreshToken 返 200、`mode=2`、身份指纹一致、新 token 打 RPC 直接 200。临期前 5 分钟主动续，一路用不到 401。稳态下打开面板：已有凭据的账号**零请求**，只有一条凭据都没有的账号才需要首次登录；会话齐了之后**并发**查询全部账号，不用逐个等。底部有 `N / M` 进度，撞平台软频控会自动中止并说明卡在哪个账号
- **续期有身份核对（防串号）**：平台对「签名非法的 token」只会铸出设备匿名令牌（`oasis_id` 不同、RPC 401）。所以续期拿到新 token 后必须比对 `oasis_id|organization_id`，对不上就整条会话丢掉并落回密码重登——绝不让 A 的设备令牌顶替 B 的会话
- **切号不再清别人的会话**：各账号数据与凭据各自独立，切走再切回仍是本地缓存命中，不必重新登录
- **未查过的账号显示「—」而不是 ¥0**：「查到了 0」和「没查过」是两件事，界面不许含糊
- **侧栏入口胶囊**：阶跃模式下可显示 Credit 月池剩余 % 或账户余额（设置里二选一），悬停仍浮出基元的限时余额时间线

### ZCode（v0.5.0 新增，默认关闭）
- **总开关**：本插件面向所有用户发放，读本机 ZCode 凭证的能力**默认关闭**——设置弹窗「ZCode 集成」卡里显式「开启」后，面板标题切换器才会出现第三段「ZCode」，插件后台才被允许访问 `~/.zcode/v2`（host 侧路由同样有门禁，双重保险）；关闭即停读，面板恢复原样
- **用量页签**：读取本机 `~/.zcode/v2` 的 ZCode 桌面端登录凭证，直连官方接口查询当前套餐（档位 / 到期 / 剩余额度 / 已用占比）；BigModel 通道优先，自动回退 z.ai 余额接口，兼容个人订阅与活动赠送多套餐切片。每 60 秒自动刷新
- **活动页签**：列出可领取的 ZCode 活动套餐（赠送内容、周期），一键领取——领取前自动打激活埋点，通过阿里云验证码（先 8 秒无感验证、风控时转滑块）后自动提交；验证码弹窗页由插件后台伺服，若被页面 CSP 拦截会自动回退到 127.0.0.1 一次性端口完成，结果回传面板
- **入口胶囊**：切到 ZCode 时侧栏胶囊同步换成 ZCode 身份（闪电图标 + 套餐剩余百分比），无数据时自动回落基元余额
- 凭证解密、token 候选与请求头伪装逻辑移植自开源工具 [zcode-switch](https://github.com/pjpv/zcode-switch) v1.5.4（MIT），并用其跨语言测试向量对拍锁定
- **安全与风险**：ZCode 凭证只在插件后台内存与 `~/.zcode/v2` 本机文件中出现，浏览器只见掩码；相关接口为官方未公开接口、请求头伪装成桌面端，存在被平台风控的可能，请自行斟酌使用

### 设置（面板右上角 ⚙，弹窗打开）
- **账号管理**：添加 / 一键切换 / 删除**多个**基元律动账号，密码保存在本机、随时可明文查看
- **入口胶囊余额**：侧栏入口胶囊显示「总余额」或「限时总余额」，点击即切换并记住选择
- **插件更新**：自动比对 npm 最新版本（24 小时缓存），有新版时状态转高亮并提供「复制更新命令」，只提醒不自动执行
- **备用粘贴**：网页会话 Cookie（`tr_session`）兜底登录（默认折叠，用的时候展开）

## 安装说明

任选以下一种方式安装，**安装后需重启 DSH**，侧栏底部才会出现入口。

**方式一：插件市场**（收录后可用）

在 DSH 插件市场搜索「基元律动费用中心」或 `dsh-tokenrhythm-bill`，一键安装。

**方式二：命令行 · npm 源**（推荐，秒级安装）

```sh
dsh plugin --profile web add dsh-tokenrhythm-bill
```

> 已装过旧版本？重复执行上述命令即可**更新**到最新版，然后重启 DSH。

## 首次配置

1. 点击侧栏底部「基元律动-费用中心」入口 → 右上角 ⚙
2. 添加基元律动**账号和密码**并登录（一次性；密码只保存在本机）
3. 回到「余额 / 用量 / 模型 / 状态 / 密钥」页签即可使用（面板默认落在余额页），入口右侧会常驻显示当前账号总余额

> **平台登录接口不可用时**：浏览器登录 [tokenrhythm.studio](https://tokenrhythm.studio) → F12 → 应用 → Cookie → 复制 `tr_session` 的值，粘贴到「备用：粘贴网页会话 Cookie」框中保存（直接粘贴 `tr_session=sess_…` 整串也认）。Cookie 过期后余额页签会引导你回设置重新登录。

> **会话自动续期**：登录成功后 Cookie 保存在本机并自动复用；粘贴新 Cookie 即完成切换账号（自动识别身份）。会话过期时，若该账号已保存密码则**自动重登同一账号**并继续刚才的操作，全程无感；未保存密码的账号才会提示重新登录。

## 隐私说明

- 账号密码与会话 Cookie 只保存在**本机**，**永不下发浏览器**
- 界面中的 API Key / Cookie 一律显示掩码；完整值仅在你主动点击时才复制到剪贴板

## 常见问题

- **余额页签有几天是虚线空格？** 就是那几天没有调用。30 格里调用数与花费的合计和汇总页签是逐位相同的（实测算术：`/api/usage-daily` 分桶 30 天 = `/api/usage/panel?range=30d` 的 summary），所以空格子是真空，不是页面坏了。日历标题行右上角的角标会写明 `N / 30 天有调用 · 明细起 XXXX-XX-XX`。
- **资金明细里的行怎么还有「剩 ¥0」的？** 那是用完了的额度（`USED_UP`）。留着它是为了说清历史——「累计赠送 ¥184」这个数只有把每一笔赠送都列全才对得上；删掉用完的，账就平不了了。这些行整行压暗，不抢眼。
- **切换账号后数据变成 ¥0？** 余额、用量都按账号隔离——切到没用过的账号自然为空，切回原账号即恢复原数据。
- **阶跃「账户」页签里另几个账号显示「—」？** 那是自动补齐还没跑到它（首次冷启动要依次给缺会话的账号登一次），或撞上了平台软频控被中止——底部会写清卡在哪个账号、还剩哪些。补齐完成后切走再切回仍是本地缓存命中，不必重查。
- **余额显示「会话已过期」？** 到设置页重新登录，或重新粘贴 Cookie。
