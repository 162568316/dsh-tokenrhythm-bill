# dsh-tokenrhythm-bill

**基元律动费用中心** —— DeepSeek Harness（DSH）插件，把[基元律动 tokenrhythm.studio](https://tokenrhythm.studio) 的模型清单、账户余额、用量与密钥管理，集中到侧栏底部一个小面板里；另支持阶跃星辰（StepFun）Step Plan、ZCode 桌面端套餐额度、[清枢智汇 tierflow.cn](https://tierflow.cn) 与 [OpenCSG opencsg.com](https://opencsg.com) 的**可选**接入（默认只显示基元，另四家在 **设置 → 系统管理** 里勾上才出现）。

在 DSH 侧栏底部（设置按钮上方）点击「基元律动-费用中心」入口即可打开可拖拽面板；也可以直接按 **`Ctrl+J`**（macOS `Cmd+J`）呼出/收起。入口左侧是品牌标 + 名称，右侧常驻**总余额胶囊**（切号即刷、预警转琥珀色）；**悬停入口**可浮出**限时余额时间线**——逐笔列出每笔限时额度和「N 天后失效」；侧栏收起时只保留品牌图标。

## 功能一览

### 通用
- **侧栏入口胶囊**：常驻当前系统总余额（低余量转琥珀色），悬停浮出限时余额时间线；基元模式下设置里可在「总余额 / 限时总余额」间切换，另四家各有自己的口径（见下）
- **快捷键 `Ctrl+J`**（macOS `Cmd+J`）：呼出/收起面板，已自动列进 **设置 → 快捷键**，可改键或改成「仅菜单呼出」
- **设置 → 系统管理**：基元律动 / 阶跃 / ZCode / 清枢智汇 / OpenCSG 五个开关，**默认只勾基元律动**；没勾的连切换器分段、页签、设置分组都不出现，勾选当场落盘。**整行按住就能拖动排序**（竖向移动几像素才算拖，没动就松手仍是勾选/取消）——拖出来的顺序同时决定这里的行序、标题旁的系统切换器分段、设置里的分组页签（「系统管理」「关于」钉在头尾），顺序也当场落盘，重启后保持
- **多账号**：基元 / 阶跃 / 清枢 / OpenCSG 都可配多个账号（ZCode 读本机桌面端凭证，没有账号池）；密码只存本机、界面只见掩码，明文按需单取；「显示」只换面板看谁的数，不切登录身份、不清别人会话

### 基元律动（tokenrhythm）
- **余额页**：账户余额大字 + 限时额度占比条（蓝＝不会过期的钱、橙＝会过期的钱）+ 倒计时胶囊，有冻结金额一并显示；**当日使用**（调用次数、输入/输出/缓存 tokens 与命中率、当日花费）；**资金明细**逐笔列出还能用的充值本金与赠送额度（已用/还剩/何时到期，临期排前，已用完的不占行）；数据账号行带**实名徽章**；每 60 秒自动刷新
- **兑换码**：余额页输入体验卡兑换码，流程与平台网页一致——先二次确认再提交，成功显示「已到账 ¥x.xx」与有效期，失败原样显示平台原话
- **用量页**：近 30 天总花费 / 调用 / Tokens + 4 张指标卡（成功失败、中止、输入输出、缓存命中率）、**30 天热力日历**（一格一天，悬停有调用的格子看当日明细）、**按模型 / 客户端**拆分排行；每 90 秒刷新
- **模型页**：分类筛选（全部/文本/图像/音频/视频/向量，带计数）+ 卡片网格，每张卡给出状态胶囊、模型 ID 与来源、序列长度与模态、输入/输出/缓存命中单价与图片单价（折扣时划线标原价）
- **状态页**：用自己的 Key 对勾选的 chat 模型做**真实 1-token 探测**（约 ¥0.0004/模型，计入你的账单），逐行给出状态点与首字延迟，可设定时间隔自动重测（只在面板打开期间跑）
- **密钥页**：平台 API Key 列表（平台只回掩码）。在本面板**新建的 Key 当场在本机存一份明文副本**，之后随时能「复制完整值」，不想留就点「不再在本机保存」（只删本机副本，平台上的 Key 不动）；DSH 正在使用的那把即使不是本面板建的，也能凭头尾指纹一键复制；在官网删过的 Key，其残留本机副本会提示一键清理。平台列表没有按 id 单取明文的口——所以没存过副本的旧 Key 只能看掩码
- **对话头部角标**：当前对话在用基元模型时，「对话 / 轨迹」页签同一行右端出现一枚**账户余额**角标（与面板余额页同一个数；**可用余额低于 ¥10 转琥珀**，与侧栏预警同一个阈值；左侧一枚**余量状态点**：绿 = 有读数 / 琥珀 = 低余量 / 灰 = 没读到）；悬停出自绘详情卡（账户余额 → 限时额度 / 冻结（有才列）→ 使用密钥名字 → 数据更新于），**一轮对话结束即时刷新**

### 阶跃星辰（StepFun）
- **账户页**：配置的全部阶跃账号各列一张卡，每张卡带**账户余额**与 **Credit 月池**（百分比 + 进度条 + 套餐档位水印 + 月池重置时间，波峰波谷计费的订阅另挂计价标识）；每张卡可单独**查询此账号 / 展开近 7 日 Credit 消耗 / 删除**，账号增删都在这一页
- **卡顶行**：头像 · 用户名（昵称）+ 实名徽章 · 登录手机号 · 密码胶囊（默认打码，点一下显明文）· 显示 · 删除
- **会话按账号分槽**：各账号会话独立保存、过期自动续期（不用重输密码），切号不清别人的会话；未查过的账号显示「—」而不是 ¥0
- **密钥页**：阶跃控制台「接口密钥」的新建 / 复制完整值 / 删除，列表只显示掩码；列表接口每次都能按 keyId 再要一次完整值，所以**不在本机另存副本**（少一处明文落盘点），「复制完整值」随时可用
- **「设为使用」**：一键把 DSH 实际在用的 `STEP_API_KEY` 换成某个账号的某把 key（两段式确认，在用那张卡挂「使用中」徽标并整卡高亮），写宿主凭据文件是行级手术 + 原子替换 + 回读校验，**无需重启，下一句对话就走新 key**
- **对话头部角标**：当前对话在用阶跃模型时，「对话 / 轨迹」页签同一行右端出现一枚**套餐剩余进度条**（`昵称 ▓档位▓ 56.8%`，剩余不足 20% 转琥珀；左侧一枚**余量状态点**：绿 = 有读数 / 琥珀 = 低余量 / 灰 = 没读到）；悬停出自绘详情卡（使用密钥名字 → Credit 剩余/总量 → 月池重置 → 套餐档位 → 数据更新于），**一轮对话结束即时刷新**

### ZCode（默认关闭）
- 读取本机 ZCode 桌面端登录凭证（`~/.zcode/v2`，跟随数据目录设置），查询当前套餐：档位 / 到期 / 剩余额度百分比 / 已用占比 / 分项限额；入口胶囊同步换成 ZCode 身份

### 清枢智汇 TierFlow（默认关闭）
- **账户页**：一个账号一张卡 —— **不限时余额**｜**限时余额（全部到期合计）**两格数据 + 铺满整卡的两段余额条与「限时占 x%」图例（右端挂「购买订阅」）；每张卡可**显示 / 查询此账号 / 购买订阅 / 删除**
- **套餐用量页**：全部订阅逐条渲染（剩余天数、期限两端、剩余套餐额度与剩余 Token 池两条进度条），生效中的那份带徽章与高亮；「升级套餐」在面板内弹窗，**只用余额付差价**（host 下单前复问报价，对不上不扣款）
- **购买订阅**：在每张账号卡上，**只能用余额**新开一份订阅（两步确认，余额够不够只当提示、由平台判）
- **密钥页（API Key）**：按量计费密钥的列表 / 创建 / 启停 / 删除（官网 `/keys/` 同款能力，与 OpenCSG 同一套本机留存设计）——平台列表只回服务端掩码，**完整密钥只在创建的那一次由平台给出**，在本面板创建的当场存一份本机明文（之后随时「复制完整值」，不想留可单条「不再在本机保存」）；在官网创建的只有掩码。金额列（剩余 / 已用）按平台 `quota_per_unit` 折成「元」显示，基准取不到时显示「—」绝不写 0
- **入口胶囊**口径四选一：总余额 / 限时余额 / 套餐余额 / 套餐 token

### OpenCSG（默认关闭）
- **账户页**：一个账号一张卡 —— **账户余额**（次级行摊开现金/赠送构成）｜**待发放余额**；卡脚常驻数据时间，可单卡刷新；账号卡按「当前显示」置顶
- **用量页**：三段式 = **本期汇总**（本月 1 号 → 今天的花费 / 调用 / 总 Tokens）→ **今日一格** → **按接口拆分**（份额条 + 花费，同名接口先聚合）
- **API Key 页**：列表 / 创建 / 删除（门户 `/settings/api-keys` 同款能力）；平台列表只回掩码、也没有按 id 单取明文的口，所以**创建的密钥当场在本机存一份明文副本**，之后随时能「复制完整值」，不想留就点「不再在本机保存」（只删本机副本，平台上的密钥不动）；在官网删过的密钥，其残留本机副本会提示一键清理（不自动清——明文删了就回不来）
- **入口胶囊**口径三选一：账户余额 / API 调用量 / 待发放余额
- **对话头部角标**：当前对话在用 OpenCSG 模型时，页签行右端出现一枚**账户余额**角标（低余量吃平台自己的 `low_balance_warn` 阈值转警示色；左侧一枚**余量状态点**：绿 = 有读数 / 琥珀 = 低余量 / 灰 = 没读到）；悬停详情卡逐行「使用密钥 → 账户余额 → API 调用量 → 待发放余额 → 数据更新于」，**一轮对话结束即时刷新**

### 对话输入行的两个图标按钮
- **计划** 与 **压缩** 挂在模型选择器左边：**压缩** = 执行官方的 `/compact`（不消耗模型轮次，上下文占用超 60% 转红），**计划** = 切换计划模式（激活后转蓝，再点退出）；状态读宿主投影
- 输入行**一个文字都不出**：两个按钮成功静默，失败只把图标转红 6 秒、原因写进自己的 tooltip；对话正在跑时压缩按钮禁用

## 安装说明

任选以下一种方式安装，**安装后需重启 DSH**，侧栏底部才会出现入口。

**方式一：插件市场**（收录后可用）—— 搜索「基元律动费用中心」或 `dsh-tokenrhythm-bill`，一键安装。

**方式二：命令行 · npm 源**（推荐，秒级安装）

```sh
dsh plugin --profile web add dsh-tokenrhythm-bill
```

> 已装过旧版本？重复执行上述命令即可**更新**到最新版，然后重启 DSH。

## 首次配置

1. 点击侧栏底部「基元律动-费用中心」入口 → 右上角 ⚙
2. 添加基元律动**账号和密码**并登录（一次性；密码只保存在本机）
3. 回到各页签即可使用，入口右侧会常驻显示当前账号总余额
4. 要用阶跃 / ZCode / 清枢智汇 / OpenCSG：**设置 → 系统管理**里勾上，再去面板「账户」页签加账号

> **平台登录接口不可用时**：浏览器登录 [tokenrhythm.studio](https://tokenrhythm.studio) → F12 → 应用 → Cookie → 复制 `tr_session` 的值，粘贴到「备用：粘贴网页会话 Cookie」框中保存（直接粘贴 `tr_session=sess_…` 整串也认）。会话过期时，已保存密码的账号会**自动重登同一账号**，全程无感。

> **面板提示「未配置基元律动（tokenrhythm）提供商」？** 在 DSH 设置里加一个 baseURL 为 `https://tokenrhythm.studio/v1` 的提供商即可（名册由 DSH 自己管，插件只读）。

## 隐私与说明

- 账号密码、会话 Cookie 与令牌只保存在**本机**（host 进程内存 + 状态文件 `0600`），**永不下发浏览器**；界面里的 API Key / Cookie 一律掩码，完整值仅在你主动点击时才复制到剪贴板
- 界面上的「**—**」表示**没读到**（平台没给这个字段，或那条口这次失败），**不是 0**；`0` 会照实显示 `¥0` / `0 条`
- 升级插件后**先重启 DSH** 再勾选系统开关——宿主进程还跑着旧代码时不认识新字段，勾选会被静默丢掉
- 开了**两步验证（2FA）**的账号暂不支持（清枢智汇加账号时会明确提示，不假装登录成功）
- 快捷键是**应用内**快捷键（DSH 窗口不是焦点时按了没反应）；web 端默认 `Ctrl+Alt+J`（浏览器不转发 `Ctrl+J`）
